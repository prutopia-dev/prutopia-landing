# Signature mail Pr'UtopIA — installation

## 1. Les images en ligne

Gmail et Outlook refusent les images intégrées dans une signature. Une fois le
dossier `marque/` publié sur la landing, les images sont à ces adresses :

- `https://prutopia.net/marque/signature/sig-arbre.png`
- `https://prutopia.net/marque/signature/sig-marque.png`
- `https://prutopia.net/marque/signature/sig-binaire.png`

Vérifie que chaque adresse s'ouvre dans le navigateur.

## 2. Personnaliser et copier dans Gmail

1. Ouvre `https://prutopia.net/marque/signature/signature.html` dans Chrome.
2. Modifie les champs si besoin : nom, fonction, e-mail, téléphone, site web,
   slogan. L'aperçu suit, et un champ vide n'apparaît pas dans la signature.
   La page retient tes valeurs dans ce navigateur ; « Revenir aux valeurs
   d'origine » remet la version de départ.
3. Clique sur « Copier la signature ».
4. Gmail → ⚙ → Voir tous les paramètres → Général → Signature → Créer (ou
   choisis la signature existante) → colle → Enregistrer les modifications en
   bas de la page.
5. Envoie-toi un mail de test et ouvre-le aussi sur ton téléphone. En mode
   sombre, certaines messageries foncent le fond crème : c'est normal.

`apercu.html` contient les images intégrées : il sert seulement à voir le
résultat, pas à copier.
